# التحقق وإعادة التشغيل

`npm test` يشغل اختبارات المجال والتكامل والترحيل والحفظ والمراجع وصحة صياغة JavaScript. لا توجد تبعيات npm مطلوبة. تعمل اختبارات GitHub Actions على بيانات اصطناعية فقط.

افتح `tests/browser-runner.html` في أصل تجريبي مستقل، ثم اضغط تشغيل المجموعة. تختبر المجموعة عرض الهاتف 390px وسطح المكتب 1280px، التنقل الرئيسي والفرعي، الدفع الجزئي والمتعدد والتراجع والإعادة، تمويل الحساب، الدفع منه، الادخار، تعديل الخطة بعد الدفع، إلغاء الحوار والمجموعة، ربط رسالة الراتب ومنع تكرارها، إضافة الحساب والمشروع والاستحقاق، رسوم البطاقة، التوقع والسيناريوهات والفائض، والبيانات التالفة. تستعيد حالة بيئة الاختبار عند اكتمال التشغيل. لا تشغلها على أصل الإنتاج الذي تستخدمه للبيانات اليومية.

اختبارات الملفات الشخصية منفصلة عن المستودع وسجلات CI. لم تُرفع ملفات JSON أو أرصدة المستخدم أو ملاحظات المطابقة إلى المستودع. نجاح الاختبارات لا يعني مطابقة كشوف البنك.

## معايير المراجعة

- تحويل داخلي يحفظ مجموع النقد.
- دفع بند ممول لا يخصم الراتب ثانية.
- تغير الخطة لا يغير الحركات السابقة.
- إلغاء ربط لا يحذف حركة مستقلة.
- أصل قرض غير مثبت لا يخفض بالقسط كاملًا.
- تغير يوم الراتب وإعادة الفتح لا يولدان إيداعًا.
- تكرار الترحيل والتصدير والاستيراد يحفظ المعرفات والحقول غير المعروفة.
- تُرفض النسخة التالفة والمراجع المفقودة والمبالغ غير الصالحة.
- فشل الحفظ وتعارض نسخة التبويب لا يغيران النسخة المعتمدة.
- لا تُخفى القيم السالبة في الفائض أو رصيد التوقع.

حدود التحقق: محاكاة الهاتف داخل Chromium بعرض 390px لا تعادل تجربة جهاز Android أو iPhone فعلي. لا يوجد ربط مباشر بمؤسسة مالية.
