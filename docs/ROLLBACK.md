# الرجوع الآمن

نسخة المصدر السابقة محفوظة في الفرع `archive/before-unified-ledger-20261126` قبل تحديث الإنتاج. الرجوع البرمجي يتم بـ revert لدمج الإصدار أو إعادة نشر ذلك المصدر، مع إبقاء تاريخ Git.

المخطط ٣ يحتفظ بالحقول الأصلية، والنسخة قبل الترحيل محفوظة على الجهاز. قبل تغيير إصدار البرنامج صدّر JSON الحالي. إذا احتجت استعادة البيانات القديمة فاستورد ملف النسخة قبل الترحيل، أو استخدم نسخة الجهاز المحفوظة؛ لا تمسح التخزين المحلي أو بيانات الموقع.

للاستخدام المعتاد افتح الرابط نفسه وبالمتصفح نفسه. لا حاجة للاستيراد إذا كانت البيانات الحالية صحيحة؛ الترحيل محلي تلقائي مع نسخة رجوع. ملف التسليم المهاجر نقطة استعادة من تاريخ التسليم؛ لا تستورده فوق حركات جديدة دون تصديرها ومراجعتها أولًا.
